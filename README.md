SpaceShip Titanic Kaggle 竞赛建模项目项目概述本项目针对 Kaggle Spaceship Titanic 竞赛开展，任务是预测星际飞船乘客是否被传送到异次元空间，属于二分类机器学习任务。通过完成数据探索性分析（EDA）、数据预处理、特征工程、模型构建与调优，最终生成提交文件，首次基线模型得分 0.77507，后续可持续优化提升模型性能。竞赛地址：https://www.kaggle.com/competitions/spaceship-titanic项目目录结构plaintextSpaceship-Titanic/├── data/                  #
