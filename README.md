Spaceship Titanic - Kaggle 建模项目


项目简介
Kaggle 经典入门赛 Spaceship Titanic 太空泰坦尼克号竞赛，
使用 TensorFlow Decision Forests 随机森林 完成全流程建模。


项目内容

数据读取与缺失值填充
特征工程：船舱 Cabin 拆分、类别特征转换
训练集 / 验证集划分
随机森林模型训练、深度与树数调参
特征重要性分析
测试集预测与生成标准提交文件



技术栈
Python Pandas 数据处理
TensorFlow Decision Forests
Kaggle 竞赛完整建模流程



运行环境
Kaggle Notebook 在线运行，代码可直接复现。
